# 当下AIGC在游戏音频设计中的应用调研

## 研究背景

传统游戏音频设计的过程

1、语音: 撰写台词脚本 -> 邀请配音演员录音 -> 进行后期修音,降噪,单句导出wav -> 音频设计师在中间件中配置语音事件,抢占逻辑 -> 打包成SoundBank进入游戏引擎

2、音乐: 确定音乐风格 -> 作曲家作曲,制作管弦乐 -> 输出分轨Stem -> 音频设计师利用中间件做自适应交互音乐 -> 打包成SoundBank导入游戏引擎

3、音效: 梳理所需要的音效清单 -> 商用音效库素材叠加修改/拟音棚实物录制Foley标准化导出wav -> 音频设计师在中间件设置随机播放组,3D空间衰减,环境混响 -> 打包成SoundBank集成进游戏引擎进行反复调试试听
